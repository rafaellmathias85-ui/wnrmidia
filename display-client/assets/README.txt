Coloque aqui os arquivos de ícone do aplicativo:

  icon.ico  — ícone Windows (256x256, formato ICO multi-resolução)
  icon.png  — ícone para o system tray (16x16 ou 32x32 recomendado)

Use a mesma marca gráfica WNR Mídia (fundo escuro, símbolo dourado).
